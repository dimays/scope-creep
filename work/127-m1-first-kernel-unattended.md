The first proof of [[roadmap-002]]. Take one real kernel from the human-input log and ship it
as a periphery change on the console, with **zero Owner touches**. The path is:

1. intake
2. interpretation (the "heard" line)
3. build
4. independent review
5. merge
6. the change runs in the Owner's local console

## Acceptance
- A replayable trail exists: the kernel, the interpretation, the PR, the evidence bundle, the merge, and the running result.
- The Owner only reacts.
- It is a probe, not a gate. Run it on whatever producer works today, and learn from it.
