# Release 002 — v0.2.0 (Autonomous governance)

- **Date:** 2026-09-07
- **Scope:** control-plane (scope-creep) — with companion polish in `scope-creep-console`.
- **Version:** v0.2.0 (`MANIFEST.yaml` bumped 0.1.0 → 0.2.0 to mark the milestone). A
  hand-seeded entry, like [[release-001]] — the version-bump generator ([[work-053]]) is
  not live yet.

## Highlights
The org can now **merge its own routine code without the Owner's approval** — and, just as
importantly, it **cannot** weaken its own gates even when the Owner authorizes it. This
release built the five mechanical rails the Chief Reality Officer required, activated
[[adr-022]] (autonomous merge with independent review + escalation to the Owner on cost,
security, substantial tradeoffs, or safety-rail/core changes), and had the Owner amend the
INVARIANTS by their own hand (v1.2.0 → v1.3.0) — because the rails blocked the agent from
doing it, exactly as designed. Alongside the governance work, the Console's Explore pass
made the "hundreds of consistency issues" honest (a measurement bug: **324 → 2** real
dangling links), made Timeline entries and `[[wikilinks]]` genuinely clickable, folded the
vestigial Settings tab, added a delight pass, and fixed a version skew that had `/healthz`
under-reporting the app version.
